# Local operations

From the repository root, run `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=source python3 -m unittest discover -s tests -v`. To install into an isolated environment, create a virtual environment in `/tmp`, then run its `pip install .`; `harness-v0 --help` verifies the installed entry point. No account API key is needed because native child review is dispatched by the active Codex coordinator, not an API-backed Python client.

Create a ledger with `harness-v0 LEDGER create TASK_ID OBJECTIVE ORIGINAL_REQUEST`. Its authority policy starts unspecified; record the actual model with `replace authority FILE`. Add typed JSON records with `add SECTION FILE`; replace integration/completion/authority with `replace SECTION FILE`. `prepare-review CANDIDATE.json --type architecture --source REF` freezes a package and returns the request to send to a native semantic-review child. For code-only changes with compatibility, cross-artifact, or other semantic risk, add `--semantic-risk`; this makes review required. Once required, later review preparation retains that requirement and all previously required change-type criteria until the integrator explicitly replaces completion state. After the child returns, save the structured result and native receipt, then run `ingest-review PACKAGE RESULT ACTIVATION`. Use `disposition REVIEW_ID INDEX accepted EVIDENCE_ID` after repair. `complete` and `progress` inspect the parent state. The record files and CLI calls should be generated from the actual task, not copied from a challenge fixture.

Inspect `state.json`, `events.jsonl`, frozen packages, and `eval-results/run-index.jsonl` to reconstruct behavior. Preserve these when investigating incidents. Recovery from an invalid reviewer response is to correct its schema or retry review; an activation failure is a separate event. Rollback of a candidate artifact is a product change owned by the integrator; the append-only event history is not erased. The optional `runtime/stop_hook.py` uses `HARNESS_V0_LEDGER`; without it the hook is inert. `runtime/hooks.template.json` contains this machine's isolated test command and must be adapted before installation. Review and trust the exact hook definition in Codex before persistent use. Official [Hook documentation](https://learn.chatgpt.com/docs/hooks) describes the trust and Stop semantics.
