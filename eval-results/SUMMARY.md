# v0 evaluation summary

Seven controlled v2 packages were reviewed by seven fresh native subagents. All seven returned matching SHA-256 receipts. The clean case drew zero findings. Each of six injected defects drew at least one relevant semantic finding, but only four matched the grader's exact criterion: the unsupported decision reversal was labeled request fidelity/structural integration rather than existing-artifact fidelity, and the false completion claim was labeled information lifetime/consumer verification rather than completion. These are exact-criterion misses, not erased by the broader family-level detection. Four first responses across all native runs had schema errors (three invalid severity values and one string confidence); validation required a format retry. The initial v1 clean fixture was underspecified and drew a plausible finding, so it is diagnostic only.

In the F062 repair demonstration, one blocking lifetime finding was accepted, the transient line was removed, a subsequent artifact inspection was logged, and a new frozen package received zero findings from a fresh reviewer. This demonstrates one local defect reduction. It does not establish a general repair rate.

The historical reviewer-isolation study reported 34 paired reviewer runs with no proven quality winner and a confirmed F062 miss in both arms. Those historical results are prior evidence, not counted in this v0 score. Two real-work-derived episodes were reviewed: the F063-LIVE prompt artifact drew no finding, while this v0 implementation's first ten review rounds found 4, 2, 2, 2, 2, 1, 2, 1, 2, and 1 blocking defects, triggering repairs after each round. The tenth review required the parent task's 16 completion-set items to be tracked individually. Isolated installation and active Stop-hook continuation were observed. Cost for these v0 native calls was not instrumented at per-child token level, so token totals and dollar cost remain UNKNOWN. Later reviews are recorded in the case ledger and run index.
